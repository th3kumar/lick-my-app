Design system · v2

{{ systemName }}

Every object on screen is an outlined white shape sitting on a hard, accent-coloured offset shadow. Nothing is blurred, nothing is filled with brand colour, and the type is rounded and heavy.

Pick an accent — the whole page re-derives. Motion personality is playful: overshoot on pop, bounce on commit, and a press that physically drops the object onto its own shadow.

{{ accent }}
The two rules

1 · The chrome has no brand colour. Every saturated pixel belongs to a user-created object.

One accent value drives the offset shadow, the symbol token, the metric text, the heatmap and the day markers. Nothing else in the UI knows the colour exists.

2 · Elevation is drawn, not blurred. Outline + hard offset, always.

1.5px near-black outline, 3px/3px offset shadow at 0 blur, tinted from the object's accent. There is no blur radius anywhere in the system — which is exactly why pressing can collapse the offset and feel physical.
